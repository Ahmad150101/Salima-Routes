# Salima Routes — مخطط مسارات سليمة

لوحة عربية RTL مستقلة تماماً عن `Salima-Web` لتسجيل مواقع الزبائن ومقارنة مسارات التوزيع على الهاتف والكمبيوتر. تعمل الخريطة بلا حساب أو مفتاح API أو Billing.

## المزايا

- خريطة MapLibre GL JS مع أنماط OpenFreeMap: Liberty وPositron وDark.
- إضافة الزبون من GPS أو النقر على الخريطة أو الإحداثيات اليدوية.
- مستودع واضح، علامات مخصصة، طلبات اليوم، بحث وفلترة وتحديد جماعي.
- حفظ محلي مع migration آمنة وتصدير/استيراد JSON وفحص ملفات الاستيراد.
- ثلاثة اقتراحات: الأسرع، الأقصر، والمتوازن المقترح.
- مسارات قيادة تجريبية عبر OSRM Public Demo، مع fallback هندسي متقطع وواضح عند تعذر الخدمة.
- حساب الوقود: `المسافة كم × الاستهلاك لكل 100 كم ÷ 100`، وتكلفة اختيارية.
- PWA خفيفة، وضع ليلي، Reduced Motion، ودعم لوحة المفاتيح.

## الخصوصية

بيانات الزبائن محفوظة في `localStorage` على جهاز المستخدم فقط ولا تُرسل إلى GitHub. إحداثيات الرحلة المحددة تُرسل مؤقتاً إلى خدمة OSRM العامة عند حساب طريق قيادة؛ لا تُخزن استجابات routing في Service Worker. لا توجد بيانات زبائن حقيقية في المستودع، والبيانات المرفقة تجريبية فقط.

## التشغيل محلياً

```powershell
python -m http.server 8000
```

افتح `http://localhost:8000`. يحتاج GPS إلى localhost أو HTTPS وإذن المستخدم.

للفحص:

```powershell
npm run verify
```

## طريقة الاستخدام

1. حدد المستودع من GPS أو الخريطة.
2. اكتب اسم الزبون وحدد موقعه ثم احفظه.
3. فعّل طلبات اليوم وحدد زبونين أو أكثر.
4. أدخل استهلاك المركبة وسعر الوقود الاختياري واختر العودة للمستودع.
5. احسب المسارات واختر بطاقة لعرض ترتيبها والطريق.

## المسار الحقيقي والتقديري

OSRM Public Demo يعيد شبكة طرق قيادة فعلية ضمن حدود الخدمة العامة. عند فشل الشبكة يستخدم التطبيق Haversine ثم Nearest Neighbor و2-opt، ويرسم خطاً متقطعاً يحمل وصف «مسار تقديري مؤقت». الحد الحالي 20 زبوناً للحساب الواحد، والخدمة العامة ليست للاستخدام التجاري المكثف ولا توفر SLA.

## GitHub Pages

Workflow في `.github/workflows/pages.yml` يشغّل الاختبارات أولاً، ثم ينشر فقط ملفات الواجهة العامة. من إعدادات المستودع اختر Pages → Source: **GitHub Actions** مرة واحدة إذا لم يكن مفعلاً. جميع المسارات المحلية relative لتعمل تحت `/Salima-Routes/`.

## القيود وخطة التطوير

- البيانات محلية لكل جهاز ولا توجد مزامنة أو حسابات مستخدمين.
- OSRM العام للتجربة المحدودة فقط.
- الإنتاج المستقبلي يحتاج Backend خاصاً وقاعدة بيانات وصلاحيات واستضافة routing ذات SLA، مع تشفير وسياسة احتفاظ وموافقة واضحة على بيانات المواقع.
