# Salima Routes — سليمة | مخطط مسارات التوزيع

نسخة تجريبية مستقلة عن موقع شركة سليمة الحالي، مصممة لتسجيل مواقع الزبائن وتجربة ترتيب مسارات التوزيع.

## ما الذي يعمل الآن؟

- إضافة اسم الزبون وحفظ موقعه.
- تحديد الموقع بطريقتين:
  - GPS: زر **استخدام موقعي الحالي**.
  - اختيار الموقع بالنقر على الخريطة.
- حفظ الزبائن محلياً داخل المتصفح (`localStorage`).
- تحديد نقطة انطلاق (المستودع/السيارة) من GPS أو الخريطة.
- تحديد الزبائن الذين لديهم طلبيات اليوم.
- حساب ثلاثة اقتراحات للمسار:
  - الأوفر وقوداً (تقديري).
  - الأسرع.
  - المتوازن (أو الأقصر إذا كان يعطي ترتيباً مختلفاً).
- عرض المسار على خريطة OpenStreetMap.
- تقدير المسافة، الزمن والوقود.
- تصدير/استيراد بيانات الزبائن بصيغة JSON.
- زر بيانات تجريبية لاختبار النظام فوراً.
- تصميم RTL متجاوب مع الهاتف وبألوان وهوية قريبة من سليمة.

## تشغيل المشروع محلياً

> لا تفتح `index.html` مباشرة إذا أردت اختبار GPS. شغله من localhost.

من داخل مجلد المشروع:

```bash
python -m http.server 8000
```

ثم افتح:

```text
http://localhost:8000
```

أو باستخدام Node:

```bash
npx serve .
```

## تجربة سريعة

1. اضغط **بيانات تجريبية**.
2. ستظهر 6 نقاط تجريبية ونقطة انطلاق.
3. غيّر استهلاك السيارة إذا أردت.
4. اضغط **حساب أفضل المسارات**.
5. اضغط على كل بطاقة مسار لمشاهدة ترتيبه على الخريطة.
6. بعدها احذف البيانات التجريبية وأضف محلات حقيقية قريبة منك.

## اختبار GPS على الهاتف

Geolocation في المتصفح يحتاج HTTPS في الاستخدام العادي. لذلك عند تجربة الهاتف استخدم نسخة منشورة عبر HTTPS (مثل GitHub Pages) أو بيئة تطوير HTTPS.

## الخدمات المستخدمة في نسخة الاختبار

- Leaflet لعرض الخريطة.
- OpenStreetMap tiles لطبقة الخريطة.
- OSRM public routing endpoint لحساب المسافات والأزمنة ورسم الطرق.

لا يوجد API Key في هذه النسخة.

## مهم قبل الاستخدام التجاري

هذه النسخة **MVP / Test**. خوادم OSM/OSRM العامة ليست بديلاً عن Backend تجاري ولا توفر SLA. عند الانتقال لبيانات حقيقية كبيرة (مثلاً 100+ طلبية يومياً) يجب:

1. إضافة تسجيل دخول وصلاحيات (مندوب / محاسب / مدير).
2. نقل الزبائن من localStorage إلى قاعدة بيانات مركزية.
3. إنشاء API/Backend حتى لا يعتمد النظام على المتصفح فقط.
4. استخدام خدمة Route Optimization مناسبة للإنتاج أو استضافة Routing engine خاص.
5. إضافة عدة مركبات وتوزيع الطلبيات بينها.
6. إضافة حالة الطلبية وتاريخها والمندوب المسؤول.
7. حماية إحداثيات الزبائن باعتبارها بيانات داخلية للشركة.
